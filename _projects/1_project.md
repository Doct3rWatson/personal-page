Users can link multiple google calendars (even shared family calendars), with option to color code separate calendars for organization. The meal plan, grocery list, to-do list, and the weather and world clock widgets can be edited right from the UI. Items on the grocery list and to-do list will appear crossed out when checked off, but still visible. You can click on the 'X' next to a grocery or to-do item to remove it entirely from view. There is a button at the top of the UI for users to switch between light/dark mode, as well as a 'refresh' button if you need to refresh the view.
